# Culinary Strategy Sim — v0.3.0 (Flat Modular, No Folders)

New in v0.3.0:
- More countries + story arcs (AU-WA, JP, FR, IT, US, TH)
- Rival system: you face a rival competitor with signature menus (tracked across comps)
- Signature dish library: import competitor signatures in Menu Lab
- Fundraising mini-game: tiers add budget + obligations (miss deliverables → penalties)
- Report Card tab: win rate, avg score, fatigue avg, top failure cause

## GitHub Pages (phone friendly)
1) Unzip
2) Upload **all files to repo root**
3) GitHub → Settings → Pages → Deploy from branch → `main` / `(root)`

## Tips
- Use Build IDs (e.g. `v0.3.1-riskTuned`) and export telemetry after a season to compare what changed.
