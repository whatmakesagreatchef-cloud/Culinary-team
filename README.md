# Culinary Strategy Sim — Flat Modular (No Folders)

All files sit in the repo root so it's easy to upload on phone.

## Files
- index.html — main page
- styles.css — styling
- ui.js — UI + event wiring
- systems.js — rules, actions, scoring, week advance
- state.js — save/load/reset
- telemetry.js — log + export telemetry JSON
- data_countries.js — countries + story chapters
- data_events.js — random events

## GitHub Pages
Repo Settings → Pages → Deploy from branch → main / (root)
